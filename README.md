# CivicConnect

## Community Service Request Management Platform

CivicConnect is a community service request management platform designed to improve the way community service requests are submitted, managed, tracked and resolved.

The system aims to provide a centralised platform that improves visibility, accountability and communication throughout the service-request lifecycle.


## Project Purpose

Community service requests can be handled through multiple channels such as email, telephone calls, WhatsApp, spreadsheets and paper-based processes. This can make it difficult to track requests, assign responsibility, monitor progress and provide meaningful feedback.

CivicConnect aims to address these challenges by providing a controlled system for managing service requests from submission through to resolution and closure.
